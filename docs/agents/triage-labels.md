# Triage Labels

The canonical triage roles map directly to the labels used by this repository's local Markdown tracker.

| Role | Label | Meaning |
| --- | --- | --- |
| needs-triage | `needs-triage` | The maintainer still needs to evaluate the work. |
| needs-info | `needs-info` | The work is waiting for more information. |
| ready-for-agent | `ready-for-agent` | The work is fully specified and ready for an agent. |
| ready-for-human | `ready-for-human` | The work requires human implementation or judgment. |
| wontfix | `wontfix` | The work will not be actioned. |

Each triaged issue should carry one category role and one state role.
